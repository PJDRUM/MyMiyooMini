# SD Runtime Snapshot

This folder is a snapshot of the live launcher runtime copied from:

```text
/Volumes/MYMIYOOMINI
```

Date copied:

```text
2026-04-14
```

What is included:

- live `.allium/bin` launcher binaries from the SD card
- SD card `.allium/config` files
- SD card `.allium/version.txt`

What is not included:

- ROMs
- save data
- volatile `.allium/state` files
- source code that produced the binaries

Use this as the current device-runtime reference, not as a replacement for the Rust source tree.
